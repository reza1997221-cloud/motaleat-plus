# مطالعات‌پلاس | پایه هشتم

سورس Flutter اپ آموزشی مطالعات اجتماعی پایه هشتم.

## وضعیت این نسخه
- محتوای آموزشی درس‌های ۱ تا ۵ در قالب JSON اضافه شده است.
- درس ۱ و ۲: فصل اول «تعاون»؛ درس ۳ و ۴: فصل دوم «نقش دولت در اداره کشور».
- درس سوم بر اساس صفحات ۱۴ تا ۱۷ کتاب چاپ سیزدهم ۱۴۰۵ تنظیم شده و شامل آموزش موضوعی، خلاصه، ۱۱ پرسش تشریحی با پاسخ و ۶ تست چهارگزینه‌ای است.
- فهرست صفحه اصلی اکنون سه درس آماده را در دو فصل نشان می‌دهد.
- رابط فعلی شامل آموزش، خلاصه، آزمون کوتاه و ذخیره وضعیت مطالعه است.
- ۲۱ درس دیگر هنوز محتوای نهایی ندارند.
- این بسته فقط سورس پروژه است؛ APK در این محیط ساخته یا روی گوشی آزمایش نشده است.

## اجرای پروژه
پیش‌نیاز: Flutter SDK و Android SDK نصب و پیکربندی شده باشند.

```bash
flutter pub get
flutter run
flutter build apk --release
```

پس از build موفق، فایل نصب در مسیر زیر ساخته می‌شود:
`build/app/outputs/flutter-apk/app-release.apk`

## گام‌های بعدی
1. تکمیل درس‌های ۴ تا ۲۴ بر اساس PDF کتاب.
2. بازبینی صفحه‌به‌صفحه درس‌های ۱ تا ۵ و اصلاح احتمالی.
3. ساخت بانک سؤال و آزمون‌های فصل و جامع.
4. تکمیل فهرست ۲۴ درس، جست‌وجو و گزارش پیشرفت.
5. تکمیل خرید یک‌باره، اعتبارسنجی خرید و نسخه آفلاین.
6. تست روی دستگاه واقعی، امضای نسخه انتشار و آماده‌سازی فروشگاه.

در بخش «آزمون‌ها» اکنون می‌توان مدت آزمون را از میان ۳۰، ۴۵ و ۶۰ دقیقه انتخاب کرد. زمان‌سنج هنگام شروع فعال می‌شود و با پایان زمان، آزمون به‌صورت خودکار ثبت خواهد شد. نمره به مقیاس ۲۰ محاسبه می‌شود و در کارنامه، پاسخ‌های درست، پاسخ‌های بی‌پاسخ، درصد موفقیت و پاسخ صحیح هر سؤال نمایش داده می‌شود. این قابلیت از سؤال‌های چهارگزینه‌ای ثبت‌شده در محتوای درس‌ها استفاده می‌کند.

## ساخت APK اندروید

در این بسته گردش‌کار GitHub Actions در مسیر `.github/workflows/build-apk.yml` قرار دارد. پس از بارگذاری پوشه پروژه در یک مخزن GitHub، از زبانه Actions گردش‌کار «Build Android APK» را اجرا کنید. فایل خروجی `app-release.apk` به‌صورت Artifact با نام `motaleat-plus-release-apk` قابل دریافت خواهد بود.

برای ساخت محلی نیز Flutter SDK و Android SDK لازم است؛ سپس دستورهای `flutter pub get` و `flutter build apk --release` اجرا می‌شوند.
